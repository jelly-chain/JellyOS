# Token Unlock Tracker

Track upcoming token unlocks and vesting schedules.

## Capabilities

- **Unlock Calendar**: Upcoming unlock events
- **Supply Inflation**: Dilution impact calculation
- **Vesting Analysis**: Linear/cliff vesting schedules
- **Whale Unlocks**: Large holder unlock alerts
- **Historical Impact**: Price action around past unlocks
