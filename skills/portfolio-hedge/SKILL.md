# Portfolio Hedge

Hedge portfolio risk with offset positions.

## Capabilities

- **Correlation Hedge**: Long/short correlated assets
- **Beta-Based Sizing**: Use regression beta for hedge ratios
- **Volatility Targeting**: Dynamic hedge sizing
- **Cost Analysis**: Hedge cost vs risk reduction
- **Stress Testing**: Simulate portfolio drawdown
