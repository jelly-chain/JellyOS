# Honeypot Scanner

Detect contracts that trap buyers with sell restrictions.

## Capabilities

- **Sell Restriction Detection**: Test if sells are blocked
- **Tax Manipulation**: Detect excessive sell taxes
- **Blacklist Functions**: Address-based trading blocks
- **Pausable Trading**: Owner-controlled trading pauses
- **Simulation-based**: Simulate buy/sell before real trading
