# Options Flow Tracker

Track institutional options activity for directional signals.

## Capabilities

- **Unusual Volume**: Volume > 2x OI average
- **Block Trades**: Large single-leg trades
- **Sweep Detection**: Multi-strike sweeps
- **Dark Pool Prints**: Off-exchange activity
- **Institutional Flow**: Citi, JPM, Goldman flow
