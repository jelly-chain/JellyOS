# Mempool Sentry

Monitor the mempool for alpha opportunities.

## Capabilities

- **Pending Tx Monitoring**: Track unconfirmed transactions
- **Frontrunning Detection**: Identify frontrun candidates
- **MEV Opportunities**: Sandwich, arb, liquidation
- **Gas Price Tracking**: Real-time gas price monitoring
- **Whale Tracking**: Large pending transactions
