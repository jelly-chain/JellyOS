# Rebase Alert

Monitor rebasing tokens for supply adjustments.

## Capabilities

- **Supply Change Detection**: Track token supply changes
- **Price Adjustment Alerts**: Notify on rebase events
- **Index Tracking**: Monitor index token holdings
- **Yield Monitoring**: Track rebase yield rates
- **Protocol Integration**: Ondo, OlympusDAO, Lido
