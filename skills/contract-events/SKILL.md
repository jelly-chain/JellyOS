# Contract Events

Monitor smart contract events in real-time.

## Capabilities

- **Event Filtering**: Filter by contract, event name, parameters
- **Real-time Streaming**: WebSocket-based event streaming
- **Historical Query**: Past events with block range
- **Alert Triggers**: Custom conditions for notifications
- **Multi-Chain**: EVM chains and Solana
