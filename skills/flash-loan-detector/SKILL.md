# Flash Loan Detector

Monitor flash loan transactions for manipulation and arbitrage signals.

## Capabilities

- **Large Loan Detection**: Loans above threshold
- **Manipulation Detection**: Price oracle manipulation
- **Arbitrage Tracking**: Profitable flash arb transactions
- **Protocol Tracking**: Aave, dYdX, Uniswap flash loans
- **Profit Analysis**: Attacker profit per loan
