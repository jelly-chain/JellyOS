# Data Analytics Engine

Multi-source data analytics for sentiment aggregation, pattern recognition, and exchange flow analysis.

## Capabilities

- **Sentiment Analysis**: Twitter, Reddit, Telegram, news aggregation
- **Pattern Recognition**: Candlestick patterns, divergences, volume anomalies
- **Exchange Flows**: Reserve changes, inflow/outflow detection
- **Social Volume**: Abnormal social volume spike detection
- **On-chain Data**: GitHub activity, developer metrics

## Analysis Types

| Type | Description |
|------|-------------|
| Fear & Greed | Market sentiment scoring |
| Whale Flow | Large transaction pattern analysis |
| Social Volume | Social media volume spikes |
| Exchange Reserve | Exchange balance changes |
| GitHub Activity | Repository commit tracking |

## Commands

- `/sentiment <symbol>` — get sentiment score
- `/patterns <symbol>` — find chart patterns
- `/flow <symbol>` — check exchange flows
- `/social <symbol>` — social volume analysis
