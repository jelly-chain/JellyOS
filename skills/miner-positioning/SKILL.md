# Miner Positioning

Track Bitcoin miner behavior for macro bottom signals.

## Capabilities

- **Hash Difficulty**: Network difficulty adjustments
- **Miner Revenue**: BTC/TH/s/day profitability
- **Capitulation Detection**: Hash ribbon signal
- **HODL Waves**: Age distribution of coin supply
- **Exchange Reserves**: Miner selling pressure

## Commands

- `/miner status` — current miner metrics
- `/miner hashribbon` — hash ribbon signal
- `/miner hodlwaves` — HODL wave distribution
- `/miner capitulation` — capitulation score
